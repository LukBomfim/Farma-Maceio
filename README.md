# Farma Maceió

Site institucional da **Farma Maceió**, farmácia de bairro localizada no Jacintinho, em Maceió/AL.

🌐 **Site:** [farmamaceio.com.br](https://farmamaceio.com.br)

## Sobre a loja

A Farma Maceió atende a comunidade do Jacintinho com praticidade: você pode fazer seu pedido pelo WhatsApp e receber em casa, sem pagar entrega dentro do bairro, ou passar na loja para ser atendido pessoalmente.

### Serviços

- **Entrega grátis** no Jacintinho
- **Teste de glicemia**
- **Aferição de pressão arterial**

## Sobre o site

Página única, simples e rápida, pensada para quem acessa pelo celular. O objetivo é que o cliente consiga, em poucos toques:

- **fazer um pedido** direto pelo WhatsApp;
- **conhecer os serviços** oferecidos pela farmácia;
- **ver os horários** de funcionamento;
- **chegar à loja** com o botão de rota no GPS.

O site também traz os dados de identificação da farmácia e uma Política de Privacidade, em conformidade com a LGPD.

## Tecnologias

Feito com [Astro](https://astro.build) e [Tailwind CSS](https://tailwindcss.com), em formato estático, para carregar rápido mesmo em conexões mais lentas.

## Rodando localmente

```bash
npm install
npm run dev
```

O site abre em `http://localhost:4321`.
